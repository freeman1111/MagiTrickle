# MagiTrickle fork packages

Unofficial fork of [MagiTrickle](https://gitlab.com/magitrickle/magitrickle) by Vladimir Avtsenov and contributors,
licensed under GPL-3.0-or-later. Report problems with these builds to the fork: https://github.com/freeman1111/MagiTrickle/issues,
not to the original authors.

Source code of these builds: https://github.com/freeman1111/MagiTrickle/tree/8ee307fcfb6930ff0d0a15e088476e8600847750

Latest build, the link never changes:

# aarch64-3.10

# aarch64-3.10_kn
